## Hey, I'm Frederick Fernando

I'm a Cloud Security Specialist based in Mumbai, and I've spent the better part of a decade making sure that when things run in the cloud, they run *safely*.

My journey started with good old-fashioned penetration testing — breaking things to understand how they work — and evolved into something I find even more exciting: **securing the infrastructure that modern software is built on**. Kubernetes clusters, cloud environments, container runtimes — this is my playground.

---

### What gets me out of bed in the morning

There's something deeply satisfying about working at the intersection of **security and infrastructure**. The cloud moves fast, attackers move faster, and building systems that can detect threats in real time feels like the best kind of puzzle. I love that no two days look the same.

I'm particularly excited about:

- **Runtime security** — watching what's actually happening inside a container, in real time
- **Supply chain security** — because trusting your software starts before it even runs
- **DevSecOps** — shifting security left so it's baked in, not bolted on

---

### The career so far

I've worn a few different hats — security researcher, founding security engineer at a startup, cloud-native security SME, and most recently a Senior Threat Detection Engineer at **Tide**, where I work on detection engineering across AWS at scale.

Along the way I've had the chance to write for the **CNCF** (the folks behind Kubernetes) on topics like Falco and container image trust — which, honestly, still feels pretty cool.

---

### Beyond the terminal

When I'm not working, I'm still probably reading about technology. Tech podcasts on commutes, conferences when I can get to them, books that challenge how I think about systems. It's less obligation and more genuine curiosity — this field is just too interesting to switch off from.
